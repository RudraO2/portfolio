# The Notebook

The portfolio's local notebook contains authored essays and practical AI learning guides in `src/content/*.json`. Each entry has a descriptive URL slug, unique page title and description, an original lede, headed sections, byline, topic tags, related links, sources and its own cover illustration. Claims about recent releases link to primary material and are framed as vendor-reported results when they have not been independently measured.

The site's production build renders each route to HTML so search crawlers and link previews can read the article before JavaScript runs. It emits a sitemap, an RSS feed at `/feed.xml`, image sitemap entries and writing links in `llms.txt`. Each essay has a canonical URL, Open Graph image, Article JSON-LD, and breadcrumbs. Article dates record the local draft's authored date, 17 October 2026.

## Local review and release cadence

The initial collection of 23 essays is being published together at the author's direction. A portfolio repository has no editorial calendar, CMS scheduler or scheduled publication workflow configured. Future posts can be added as deliberate releases when they are ready; there is no need to manufacture a posting cadence for search engines.

For future posts, keep drafts unpublished until the author approves them. Use the real publication date, then rebuild and verify the sitemap and feed together. Do not change a date solely to make an older essay appear new.

## Artwork

The portfolio and notebook cover illustrations were generated specifically for this project. Article covers use descriptive alt text and a 600-pixel preview; article pages select a 1200-pixel WebP cover. The separate portfolio Open Graph JPEG supports platforms that expect JPEG previews.
